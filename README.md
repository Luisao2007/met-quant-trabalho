
# Atividade Prática (Ames Housing)
## Contexto

Este projeto é uma atividade do conteúdo de Métodos Quantitativos, cadeira disponibilizada pela Universidade de Fortaleza (UNIFOR) e mediado pelo Prof. Ricardo Carubbi, que visa ensinar-nos a explorar o mundo probabilístico através do Google Colabolatory, uma plataforma que utiliza Python como linguagem de programação e fornece recursos que tornam o aprendizado mais compreensível e melhor visibilidade. 


## Estrutura do Projeto

O projeto consiste em: 

`data/raw/`: _Dados brutos do dataset._

`data/processed/` _Dados processados do dataset._

`notebooks/`: _Área de execução do projeto, separado em 3 etapas, utilizando o Google Colab._

`requirements.txt`: _Bibliotecas necessárias para a execução correta do projeto._
## Preparando o Ambiente

Antes de mais nada, **é importante que você esteja com o Google Colabolatory aberto, logado com uma conta Google e com um notebook criado**, pois os notebooks devem ser executados por lá. 

Este ambiente **não** necessita da instalação local de nenhum arquivo, e **todas** as bibliotecas utilizadas estão listadas no `requirements.txt`.

As principais dependências do projeto são:

- **Pandas**
- **Numpy**
- **Matplotlib**

Caso seja preciso instalá-las, apesar de eles serem nativos do Colab, execute o seguinte comando no ambiente Colab:

```python
!wget https://raw.githubusercontent.com/Luisao2007/met-quant-trabalho/main/requirements.txt
!pip install -r requirements.txt
```

Isso irá baixar o arquivo `requirements.txt` do github (_que ficará no sistema de arquivos do Colab, não localmente_) e então finalmente realizar a instalação. 


## Execução

Para executar os notebooks, você deve seguir os seguintes passos:

    1. Acesse a pasta "notebooks/" deste repositório.

    2. Clique no "Open in Colab" que está contido no topo de qualquer um dos arquivos.

    3. Faça login da sua conta Google, caso já não tenha feito.

    4. Clique em "Ambiente de execução > Executar tudo" ou Ctrl + F9 no seu teclado para executar cada célula de comando
A partir daqui, você só precisará scrollar para baixo para ver os resultados da atividade.
