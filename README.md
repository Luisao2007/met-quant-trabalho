
# Atividade Prática (Ames Housing)
## 📰Contexto

Este projeto é uma atividade do conteúdo de Métodos Quantitativos, cadeira disponibilizada pela Universidade de Fortaleza (UNIFOR) e mediado pelo Prof. Ricardo Carubbi, que visa ensinar-nos a explorar o mundo probabilístico através do Google Colabolatory, uma plataforma que utiliza Python como linguagem de programação e fornece recursos que tornam o aprendizado mais compreensível e melhor visibilidade. 


## ⚒️Estrutura do Projeto

O projeto consiste em: 

`data/raw/`: Dados brutos do dataset. 

`data/processed/` Dados processados do dataset. 

`notebooks/`: Área de execução do projeto, separado em 3 etapas, utilizando o Google Colab. 

`requirements.txt`: Bibliotecas necessárias para a execução correta do projeto.
## ⚙️Preparando o Ambiente

Antes de mais nada, é importante que você esteja com o Google Colabolatory aberto, logado com uma conta Google e com um notebook criado.
